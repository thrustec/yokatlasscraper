# YÖK Atlas Intelligence — API demosu

Docker PostgreSQL üzerindeki görünümleri kullanan küçük bir FastAPI uygulaması.
Üniversite arama, program filtreleme, net sonuçları ve demo üniversitesi
ekleme/güncelleme/silme işlemlerini Swagger'da gösterebiliriz.

## Demoyu aç

Docker Desktop açıkken repo kökünde:

```powershell
powershell -ExecutionPolicy Bypass -File .\backend\run-demo.ps1
```

Tarayıcı: http://127.0.0.1:8000/docs

Endpoint yolları: `/status`, `/api/veri-kapsami`, `/api/universiteler`,
`/api/programlar`, `/api/net-sonuclari`. Üniversite ve program ayrıntıları
aynı yolların sonuna ilgili ID eklenerek okunur. Üniversite ekleme için `POST`,
güncelleme için `PUT`, silme için `DELETE` kullanılır.

Yerel kurulum ve kısa sunum akışı: [DEMO_TR.md](docs/backend/DEMO_TR.md).
Çalışan API sözleşmesi `/openapi.json` adresindedir. Önceki kapsamlı mimari ve
sözleşme belgeleri ilerideki geliştirmeler için taslaktır; bu küçük demonun kapsamı
yedi okuma ve üç üniversite yazma işlemidir. Yazma işlemleri için `.env.demo`
dosyasındaki `DEMO_API_KEY` değerini Swagger **Authorize** alanına gir.

## Veritabanı şeması

This directory contains sample outputs generated by
the YÖK Atlas schema discovery tools.

These files are for development and reference only.

The authoritative database definitions are located in:

- database/migrations/
- docs/database/data_contract_v1.json

Do not apply schema.sqlite.sql to the production database.
