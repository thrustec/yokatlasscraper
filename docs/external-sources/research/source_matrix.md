## Evidence gaps before a source can enter implementation

- Obtain and hash original artifacts/responses for selected datasets and retain them in approved artifact storage.
- For authenticated sources, obtain project-owned API credentials through a secret store; never commit keys.
- Confirm source-specific terms for redistribution and scheduled automation.
- For TÜİK and TCMB, establish exact dataflow/series IDs and metadata using authenticated catalogs.
- Test coverage, ordering and pagination on selected APIs; do not treat a portal search result as a full export.
- Compare repository schema snapshot to live PostgreSQL DDL and grants before migration design. The current workspace contains no verified live DB connection.
